# ARKITEKT - Modern Landing Page

![Project Preview](./assets/preview.jpg)

**ARKITEKT** - это современный адаптивный лендинг с чистым дизайном и анимациями. Проект идеально подходит для презентации продуктов или услуг.

## Особенности

✔️ Адаптивный дизайн   
✔️ Оптимизированная производительность  
✔️ Семантическая верстка  
✔️ Доступность (ARIA, keyboard navigation)  
✔️ CSS-анимации и плавные переходы  
✔️ БЭМ-нейминг для классов  
✔️ Кросс-браузерная совместимость  

## Технологии

- **HTML5**
- **CSS3** 
- **JavaScript**
- **БЭМ**
